Fülle die korrekten Begriffe in den Lückentext unten. Von der Auflistung bleiben zwei Begriffe übrig, die nicht passen.
\begin{itemcols}[4]
	\item demselben
	\item genau
	\item einem
	\item jedem
	\item alle
	\item keinem
	\item mehr
	\item zwei
\end{itemcols}\vspace*{14pt}
{\bf Lückentext:}
\begin{spacing}{1.5}
	{\Large Bei einer Funktion wird \gap{3} Element des Definitionsbereichs\\ \gap{3} ein Element des Wertebereichs zugeordnet. Dabei kann es vorkommen, dass mehrere oder \gap{3} Argumente \gap{3} Bild zugeordnet werden. Umgekehrt dürfen aber einem Argument nie\\  \gap{3} oder \gap{3} Bilder zugeordnet sein.\vspace*{11pt}\newline
	Die Funktion $f$ ordnet jeder reellen Zahl die fünfmal grössere reelle Zahl zu. Mit mathematischen Symbolen beschreibt man diesn Sachverhalt so: \gap{6}.}
\end{spacing}
